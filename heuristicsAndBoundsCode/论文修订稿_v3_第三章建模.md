## ⚠️ 建模核对中发现的代码问题（须先决策）

### 问题 D1：目标库存水平的相位被平移了两倍提前期

**代码事实**（`main_dual.py:48-57`、`main_seasonal.py:44-52`）：

```python
def SL_t(self, t):
    L = self.L
    mu = self.mu_t(t + L)          # ← 函数内部已经 +L
    sigma = self.sigma_t(t + L)
    ...
```

而**全部 6 处调用点**（`main_dual.py:104,116,130`、`main_seasonal.py:82,95,110`、`train_dual.py:137`、`train_seasonal.py:123`、`test_dual.py:17`）传入的都是 `t + self.L`：

```python
SL = self.para.SL_t(t + self.L)    # ← 调用时又 +L
```

**净效果**：目标库存实际使用的需求参数是 **μ(t + 2L)、σ(t + 2L)**，而非论文所述的 μ(t + L)。

**影响评估**：

| 场景 | 影响 |
|---|---|
| A = 0（当前已跑的演示样本） | **零影响**。μ(·) 恒为 μ_base，任何相位平移都不改变数值，现有全部结果与结论不受影响。 |
| A = 3 或 6（尚未执行的季节性实验） | **有实质影响**。L=2、τ=20 时，2L=4 期相当于 72° 的相位超前，目标库存会比"按到货期需求定水位"的本意提前近四分之一个周期上行／下行。 |
| 策略间公平性 | **不受影响**。LIR / WNH / NV / HEUR / DRL 全部经由同一个 `SL_t` 取值，偏移是共同的。 |

**判断**：这是一处笔误而非有意设计。依据有二：其一，`train_dual.py:61` 与 `train_seasonal.py:54` 的状态布局注释明确写着 `state[0] = SL_t(t+L)`，说明作者的心理模型是"SL 取到货期 t+L 的参数"；其二，标准基准库存目标应覆盖"提前期 + 盘点周期"即 t 至 t+L，取 t+2L 在库存理论上没有对应解释。

**两种修法（二选一，建议 A）**：

- **修法 A（推荐）**：改 6 处调用点，`SL_t(t + self.L)` → `SL_t(t)`。语义变为"SL_t 接收决策期 t，内部平移到到货期 t+L"，与函数内部实现和状态注释一致，论文可照写 SL(t+L)。
- **修法 B**：改函数定义，去掉内部的 `+ L`，调用点保持不变。等价，但函数名 `SL_t` 的语义变成"直接接收计算期"，需同步修改注释。

**重要**：无论选哪种，都请在跑季节性全网格之前完成——现有 A=0 的结果与已训练模型不受影响，无需重跑。若你决定保留现状，则论文中所有关于 SL 的表述必须改写为 μ(t+2L)，并补一句相位选择的理由。

**在本修订稿中，我按修法 A 的语义撰写（即 SL 使用到货期 t+L 的参数）。若你选择保留现状，告诉我，我改回 t+2L 的写法。**

# 第三章　问题描述与扩展马尔可夫决策过程建模

本章建立完整扩展模型（双源 ＋ 季节性，对应 `main_dual.py` 与 `train_dual.py`）；单源季节性模型（`main_seasonal.py`）为其令应急渠道恒不订货的特例。叙述顺序沿用原论文第 3 节的传统：先以自然语言完整走一遍单周期的事件流，再给出记号、假设与数学定义。

## 3.1 系统描述与基准模型

**基准系统（Yan et al., 2026）。** 原基准为周期盘点的单源库存系统。每期期初，企业收到 L 期前下达的订单并立即完成抽样检测：良率 Y_t 以概率 p 取 1，整批 q_(t−L) 单位入库；以概率 1−p 取 0，该批全部报废，本期无任何到货。记完成到货判定后的库存水平为 I_t（正值表示可用现货，负值表示欠交）。企业随后观测 I_t 与在途订单向量 Q_t = (q_(t−1), …, q_(t−L+1))，决定本期订货量 q_t。需求 d_t 随后实现，尽可能由现货满足，未满足部分延期交付。持有与缺货成本按期末库存计提，采购费仅在抽检通过后支付。

**本文的扩展。** 在上述系统上作两处扩展。**其一，需求侧**：需求不再独立同分布，其均值与标准差随时间以已知周期 τ 正弦变化，跨期仍相互独立。**其二，供应侧**：在常规渠道之外增设应急渠道，零提前期、良率恒为一、单位成本更高；企业每期同时决定两条渠道的订货量。相应地，单周期事件流在原有四步（到货判定 → 观测决策 → 需求实现 → 队列滚动）之间插入"应急即时入库"一步，且决策由标量变为二维向量（完整时序见 3.4 节）。

**沿用与新增的边界。** 系统的其余设定完全沿用基准：良率跨期独立、缺货延期交付、无固定订货成本与产能约束、初始库存为零、规划期前 L 期无在途订单到货。目标库存水平的计算沿用 Inderfurth 与 Vogelgesang（2013）型近似（原论文式(3)），本文将其中的常数需求参数替换为时变参数（式(3-6)）；应急渠道的安全水位则是本文新增（式(3-7)）。基准策略 LIR 与 WNH 的具体形式在第四章与本文新增的 NV、HEUR 一并给出，此处不再重复。

### 3.2.2 建模假设

本文的全部建模假设集中陈述如下，其中 A1、A4、A5 沿用基准模型，A2、A3、A6 为本文扩展所引入。

- **A1（良率过程）** 常规渠道良率 {y_t} 跨期独立同分布，服从 Bernoulli(p)，且与需求过程相互独立。良率在货物到达时立即通过抽样检测揭示，企业在下单时不掌握该批的良率信息。
- **A2（应急渠道）** 应急渠道零提前期、良率恒为一、供应量无上限，其订货在当期即时全额入库。该抽象对应"已完成入厂检验的合格现货"这一现实形态（见 1.1 节第 3 段）。
- **A3（需求过程与周期已知）** 需求跨期**独立但非同分布**：第 t 期需求 D_t 服从参数为 (μ(t), σ(t)) 的截断正态分布，参数按式(3-1)随时间确定性变化。**周期长度 τ 为已知常数**——这是本文时间编码设计的前提性假设：sin(2πt/τ)、cos(2πt/τ) 以及动态水位 SL(·)、S₀(t) 的计算均依赖 τ。该假设在药品场景中是合理的：疾病流行的季节周期由日历决定，企业可从历史处方数据中稳定估计；振幅 A 与基准 μ_base 亦同理。周期参数需在线估计的情形（如新发传染病）超出本文范围，列为后续工作。
- **A4（成本与需求满足）** 未满足需求延期交付；期末正库存按 h 计提持有成本、负库存按 b 计提缺货惩罚；无固定订货成本、无产能约束、无批量约束。常规渠道的采购费仅在抽检通过后支付，报废批次不产生采购支出。
- **A5（初始条件）** 初始库存 I₀ = 0，规划期前 L 期无在途订单到货（即在途队列初始化为零向量）。该条款与原论文 5.1 节的实验公平性设定一致。
- **A6（经济结构）** 成本参数满足 c₁ < c₂ < b。左侧不等式保证常规渠道的主采购地位，右侧不等式保证应急补货的边际收益足以覆盖其成本。当 c₂ ≥ b 时应急渠道永不经济，模型自动退化为单源系统（式(3-7)的退化条件）。

## 3.3 时变需求与随机良率过程

需求的均值与标准差随时间正弦变化：

> **(3-1)**　μ(t) = μ_base + A·sin(2πt/τ)，　σ(t) = cv·μ(t)

第 t 期需求服从截断于零的正态分布（负采样截断为零，对应代码 `np.where(D≥0)`，与原论文 5.3 节对 Gamma 需求的截断处理同款）：

> **(3-2)**　D_t = max{ξ_t, 0}，　ξ_t ~ N(μ(t), σ²(t))

**关于需求形式选择的说明。** 式(3-1)的三项设定各有其建模依据。**其一，采用正弦而非分段常数或阶跃形式**：疾病流行强度的上升与回落是渐进的，处方需求相应呈平滑过渡而非突变；正弦形式以最少的参数（μ_base, A, τ）刻画这一平滑周期性，且其一阶导数连续，避免了在相位切换点上人为制造决策断点。**其二，采用乘性标准差 σ(t) = cv·μ(t) 而非加性形式**：这一设定意味着变异系数在周期内保持恒定，即流行季的绝对波动更大、相对波动不变。其经济含义是需求的不确定性来自"到诊人次"的比例性波动而非固定规模的噪声，这与计数型需求（处方笔数）的常见统计性质一致；若改用 σ 恒定的加性形式，则淡季的相对不确定性将被夸大，进而导致淡季安全库存被系统性高估。**其三，参数已知且跨期独立**（假设 A3）：本文关注的是"已知季节结构下如何做出最优跨期—跨渠道权衡"，而非"如何从数据中识别季节结构"，故将参数估计问题剥离。

**良率过程。** 常规渠道良率 y_t 独立同分布服从 Bernoulli(p)：订单量 q 成功则整批入库，失败则整批为零。应急渠道无随机扰动。需求序列与良率序列相互独立，且在训练与评估中均由**成对种子**预生成：seed₁ 控制需求、seed₂ 控制良率。这是对原论文"每条测试轨迹使用不同随机种子且不重复使用"（原文 5.1 节）协议的强化——不仅保证轨迹间独立，还使所有对比策略面对**完全相同的需求与良率场景**，从而消除抽样误差对策略间比较的干扰。

| 分量 | 维度 | 含义 |
|---|---|---|

### 3.5.2 马尔可夫性的恢复

**原始状态的非时齐性。** 令原始状态 x_t = (I_t, Q_t)。给定动作 a_t，下一期状态由 x_(t+1) = f(x_t, a_t, D_t, y_(t+1)) 决定，其中 D_t 的分布由式(3-2)给出而**显式依赖 t**。因此转移核 P(x_(t+1) | x_t, a_t) 随 t 变化，{x_t} 是非时齐（time-inhomogeneous）马尔可夫链。其直接后果是：在只依赖 x 的平稳策略类中不存在最优策略——存在 t₁ ≠ t₂ 使 x_(t₁) = x_(t₂)，但由于 t₁ 处于需求上行段而 t₂ 处于下行段，二者的最优订货量不同。这一现象即状态混淆（state aliasing）。

**扩充后的时齐性。** 令 φ(t) = (sin(2πt/τ), cos(2πt/τ), t/T)，扩充状态 s_t = (SL(t+L), x_t, φ(t))。

> **命题 3.1（状态的信息完备性）**　设 T 有限且 T ≥ 1。映射 φ 在 {0, 1, …, T−1} 上是单射，因而存在 φ⁻¹ 使 t = φ⁻¹(φ(t))。
>
> *证明*：设 φ(t₁) = φ(t₂)，比较第三分量得 t₁/T = t₂/T，故 t₁ = t₂。∎

由命题 3.1，给定 s_t 即可唯一确定 t，进而唯一确定需求分布参数 (μ(t), σ(t))；良率分布与 t 无关。因此 P(s_(t+1) | s_t, a_t) 不再显式依赖 t，扩充后的过程是时齐马尔可夫决策过程，在只依赖 s 的平稳策略类中寻找最优策略是适定的。

**注记 3.1（为何三个时间特征缺一不可）。** 命题 3.1 只用到了 t/T 这一个分量，可能引起"sin/cos 是否冗余"的疑问。需要区分两个层次：**信息完备性**由 t/T 单独保证，但它只是马尔可夫性的充分条件，**并不保证容量受限的神经网络能够有效利用该信息**。三个分量各自承担不同职能：

1. **t/T——信息完备性与期末效应**。它是唯一在整个规划期上严格单调的分量，既保证了命题 3.1 的单射性，又直接编码"距回合结束还有多远"。有限期 MDP 的最优策略在规划期末段应当收缩补货（新订常规货物可能在回合结束后才到货，徒增持有成本），这一非周期性的信息只能由 t/T 提供。
2. **sin(2πt/τ), cos(2πt/τ)——可学习性**。需求参数是 t 的周期函数：μ(t) = μ_base + A·sin(2πt/τ)。若网络只接收 t/T，它必须在输入区间 [0,1] 上拟合一个含 T/τ 个振荡周期的函数（本文 T=100、τ=20 时为 5 个完整周期），这对隐藏层为 [16,32,32] 的多层感知机是困难的任务，且泛化性差。而一旦输入 sin(2πt/τ)，μ(t) 便成为输入特征的**仿射函数**，网络无需拟合任何振荡即可获得需求水平信息。换言之，三角编码不增加信息量，但极大降低了利用该信息的函数逼近难度。
3. **cos 相对 sin 的必要性——相位无歧义与表示连续性**。单用 sin 存在相位歧义：sin(θ) = sin(π−θ) 使需求上行段与下行段的编码值相同，而二者的最优决策不同（上行段应当积累库存，下行段应当消化库存）；补入 cos 后 (sin, cos) 唯一确定周期内相位。此外，(sin, cos) 在周期首尾连续——t = τ−1 与 t = 0 在编码空间中相邻，而任何基于 t mod τ 的标量编码都会在此处产生跳变。

**注记 3.2（策略网络为何不直接接收 SL 分量）。** 原论文将 s_t = (S_L, I_t, Q_t) 整体输入网络（输入层 L+1 个节点，原文表 A.1）；本文网络的输入为状态向量去除 SL 分量后的 L+3 维向量 (I_t, q_(·), sin, cos, t/T)，SL 仅在网络之外的线性路径缺口结构中使用（式(4-5)）。理由有三：(i) 由命题 3.1，SL(t+L) 是时间特征与系统参数的确定函数，其信息已由 (sin, cos, t/T) 完全携带，重复输入不增加信息；(ii) 路径缺口对 SL 是线性的，交由外层线性结构处理可避免非线性网络重复拟合一个已知的线性关系；(iii) 状态向量的定义仍包含 SL（式(3-3′)），与原论文"状态增广含目标水位"的建模哲学兼容，差异仅在于策略网络内部的分工。

**注记 3.3（周期计数约定与原论文的等价性）。** 原论文计数 t = 1, …, T 并以 α^(t−1) 折现；本文代码计数 t = 0, …, T−1 并以 α^t 折现。二者的逐期事件顺序与折现权重完全一致（同一期的成本获得同一权重），仅索引起点的约定不同。本文所有公式按代码约定书写。

## 3.6 双渠道动作空间

动作为二维非负向量 a_t = (q₁ₜ, q₂ₜ) ∈ ℝ²₊：

- **q₁ₜ**：常规渠道订货量，经 L 期后在第 t+L 期受良率 y_(t+L) 支配，整批到货或全部报废；
- **q₂ₜ**：应急渠道订货量，当期即时全额入库。

相较原论文的标量动作，搜索空间由 ℝ₊ 扩展至 ℝ²₊。这一扩展带来两点方法论后果。**其一**，二维动作使得纯粹的无先验探索在样本效率上更为不利，构成第四章"双重教师锚定"设计的直接动因。**其二**，两个分量并非可分离决策：q₁ₜ 决定 L 期后的库存水位、进而决定彼时 q₂ 的触发概率，而 q₂ 的可得性又允许 q₁ 运行在更低的水位上。因此联合最优策略不等于两个单渠道最优策略的叠加——这一点在第五章的轨迹分析（5.4 节）中得到实证印证。

## 3.7 单期成本函数与目标函数

第 t 期的折扣成本为（[x]⁺ = max{x, 0}）：

> **(3-3)**　C_t = α^t · ( c₁·q_(t−L)·y_t + c₂·q₂ₜ + h·[I_t]⁺ + b·[−I_t]⁺ )

其中 I_t 为步骤④（需求消耗）之后的期末库存。三点实现细节与原论文完全一致，须在此明确：**其一**，常规采购费仅在订单成功到货时计价（c₁·q·y），报废批次不产生任何采购支出——这对应现实中"抽检不合格则退货或索赔"的商务安排，也是原论文 c_t = c_o·q_(t−L)·y_t + H(I_t) 的口径。**其二**，本期成本由 L 期前的订货决策 q_(t−L) 驱动，当期决策 q₁ₜ 不会立即体现在 C_t 中，存在滞后效应；这是提前期在成本结构上的体现。**其三**，应急成本按实际入库量计价且发生在需求消耗之前，持有与缺货惩罚则按需求消耗后的期末库存计提。

规划期内的总期望折扣成本及优化目标为：

> **(3-4)**　J(π) = 𝔼[ Σ_(t=0)^(T−1) α^t · C_t(s_t, a_t) ]，　π\* = arg min_π J(π)

该形式与原论文 min E[Σ α^(t−1) c_t] 同型（参见注记 3.3 的计数约定换算）。

## 3.8 动态目标库存与应急安全水位

### 3.8.1 常规渠道的动态目标库存

常规渠道的目标库存水位沿用 Inderfurth 与 Vogelgesang（2013）型近似（原论文式(3)），并将其中的常数需求参数替换为指定期的时变参数：

> **(3-5)**　SL(u) = (L+1)·μ(u) + k·√[ (L+1)·σ²(u) + max(L,1)·(ρ_Y²/(1−ρ_Y²))·(μ²(u) + σ²(u)) ]
>
> 其中 ρ_Y = √((1−p)/p)，k = Φ⁻¹(b/(b+h))

平方根内第二项 (ρ_Y²/(1−ρ_Y²))·(μ²(u)+σ²(u)) 刻画了全有或全无良率沿提前期造成的方差放大效应：p 越小则 ρ_Y 越大，该项越大，目标水位相应抬高。状态中使用的是 SL(t+L)：订单于第 t 期下达、第 t+L 期到达，故以到达期的需求参数确定目标水位。当 A = 0 时 μ(·) ≡ μ_base、σ(·) ≡ cv·μ_base，式(3-5)严格退化为原论文式(3)的静态形式——这为扩展模型的向后兼容性提供了解析层面的验证。

**注记 3.4（冻结参数近似的诚实声明）。** 式(3-5)是一个**冻结参数近似**（frozen-parameter approximation），而非精确的时变推广。原公式的推导前提是覆盖期内需求同分布，其中 (L+1)·μ(u) 一项的含义是"L+1 期需求之和的均值"；在平稳设定下该项等于 Σ_(v) μ_D，而在季节性设定下把它写成 (L+1)·μ(u) 隐含了"覆盖期内的需求参数冻结在第 u 期水平"的假设。更精确的做法是采用累加形式 Σ_(v=u−L)^(u) μ(v) 与 Σ_(v=u−L)^(u) σ²(v)。本文保留冻结形式有两点理由：**其一**，SL(·) 在本文中并非最终决策而是**参考基准**——路径缺口以 SL 为起点，最终订货量由网络在教师权重邻域内加权聚合得到（式(4-5)(4-6)），近似误差可被网络的权重调整部分吸收；**其二**，保持与原论文式(3)形式上的严格一致，使 A = 0 时的退化关系精确成立，便于向后兼容性验证。当 A/μ_base 较大且 τ 与 L 可比时，该近似的相位误差与幅值误差将上升；采用累加形式的敏感性对照列为后续工作。

### 3.8.2 应急渠道的安全水位

应急渠道零提前期、良率恒为一，其单期决策退化为标准报童问题：多订一单位的边际成本为 c₂ + h·P(不缺货)，少订一单位的边际成本为 (b − c₂)·P(缺货)，令二者相等即得临界分位数 (b − c₂)/(b + h)。据此定义应急安全水位：

> **(3-6)**　S₀(t) = μ(t) + Φ⁻¹( (b − c₂)/(b + h) )·σ(t)；　若 c₂ ≥ b 则 S₀(t) ≡ 0

退化条件 c₂ ≥ b 对应假设 A6 的右侧不等式失效：此时应急补货的单位收益不足以覆盖成本，理性策略永不启用该渠道，模型退化为单源系统。注意 S₀(t) 使用**当期**参数 μ(t)、σ(t)（而非 SL 那样的到达期参数），因为应急订货当期即时入库、当期即被消耗，其覆盖期只有一期——这一区别在实现上对应 `S0_t(t)` 与 `SL_t(·)` 不同的时点参数。

**注记 3.5（逐期计算水位的文献先例）。** "为每一期分别计算目标库存水位"的做法并非本文首创：原论文在附录 D.2 处理非独立同分布需求时即采用了逐期的 S_L^t（依 Inderfurth & Kiesmüller, 2015）。本文的差异在于以正弦参数化给出了该逐期水位的闭式表达，从而使其可以作为状态分量被策略网络实时利用，而不必逐期离线求解。
