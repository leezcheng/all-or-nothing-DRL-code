## D1【高】目标库存水平的相位被平移了两倍提前期

**代码事实**

```python

def SL_t(self, t):
    L = self.L
    mu = self.mu_t(t + L)      # ← 函数内部 +L
    sigma = self.sigma_t(t + L)
    ...
```

而全部 8 处调用点传入的都是 `t + L`：

| 文件 | 行 | 调用 |
|---|---|---|
| `main_dual.py` | 104 / 116 / 130 | `self.para.SL_t(t + self.L)` |
| `main_seasonal.py` | 82 / 95 / 110 | `self.para.SL_t(t + self.L)` |
| `train_dual.py` | 137 | `self.model.SL_t(t + self.L)` |

**净效果**：目标库存实际使用的是 **μ(t+2L)、σ(t+2L)**，而非注释与论文所述的 μ(t+L)。

**影响**

| 场景 | 影响 |
|---|---|
| A = 0（已跑的演示样本） | **零影响**。μ(·) ≡ μ_base 为常数，相位平移不改变任何数值；现有结果、已训练模型、论文第五章数字全部有效。 |
| A ∈ {3, 6}（未跑的季节性网格） | **有实质影响**。L=2、τ=20 时 2L=4 期 = 72° 相位超前，目标水位会比"按到货期定水位"的本意提前近 1/4 周期上行／下行。 |
| 策略间公平性 | **不受影响**。五种策略共用同一个 `SL_t`，偏移是共同的。 |

**判断**：应为笔误。依据：(i) `train_dual.py:61` 与 `train_seasonal.py:54` 的状态布局注释写的是 `state[0] = SL_t(t+L)`，说明作者的心理模型是"SL 取到货期 t+L 的参数"；(ii) 标准基准库存目标覆盖"提前期 + 盘点周期"即 t 至 t+L，取 t+2L 在库存理论上无对应解释。

**建议修法（A）**：改 8 处调用点，`SL_t(t + self.L)` → `SL_t(t)`。函数语义变为"接收决策期 t，内部平移到到货期"，与内部实现和注释一致，论文可照写 SL(t+L)。
（修法 B：删掉函数内部的 `+ L`，调用点不动。等价，但需同步改注释。）

**时机**：跑季节性全网格之前。A=0 的既有结果不需重跑。

## D2【中高·事实纠正】权重盒半宽 Δ 在 L=2 时等于 0.25，不是 0.354

**v2 初稿的错误表述**（注记4.1 与附录C 差异表）：

> "L=2 处本文取 Δ≈0.354 宽于原文 0.25——单路径情形下扰动集中于唯一路径，需更大半径……"

**代码事实**（`train_dual.py:80`、`train_seasonal.py:73`）：

```python
BASE = 0.25
w_range = (BASE ** 2 * 2 / 2 ** (self.L - 1)) ** 0.5
```

即 Δ(L) = BASE·√(2 / 2^(L−1))。逐 L 代入：

| L | 2^(L−1) | 本文 Δ | 原论文 δ | 是否一致 |
|---|---|---|---|---|
| 2 | 2 | **0.2500** | 0.25 | ✅ 完全一致 |
| 3 | 4 | 0.1768 | 0.25 | ❌ 本文更窄 |
| 4 | 8 | 0.1250 | 未报告 | — |
| 5 | 16 | **0.0884** | 0.0884 | ✅ 完全一致 |

**结论比初稿所写的强得多**：能量归一化规则在原论文报告过取值的**两个提前期上都精确复现**其人工精调结果，只在 L=3 处更保守。而且**本文实验全部取 L=2，此处 Δ 与原论文完全相同**——即当前实验中"权重盒半宽"根本不构成差异项。

**须修改的位置**：
1. 注记4.1（改写为下方 D2-新稿）；
2. 附录C 差异表中"权重盒半宽"一行——应从「修改」类移出，改列为「继承（形式化）」；
3. 1.3 贡献 (3) 的表述（本轮已在《结构诊断与第一二章》中改好）。

**注记4.2 新稿（替换原注记4.1）**

> **注记 4.2（权重盒半宽的形式化：能量归一化规则与原论文标量 δ 的关系）。**
> 原论文对权重盒半宽 δ 采取逐问题人工调定的做法：L = 2, 3 时取 0.25，L = 5 时取 0.0884（原文 5.1 节）。本文将其形式化为能量归一化规则
> Δ(L) = BASE·√(2 / 2^(L−1))，BASE = 0.25，
> 其设计意图是使全部路径上权重扰动的平方和满足 Σ_j Δ² = 2^(L−1)·Δ² = 2·BASE²，即**总扰动能量与路径数无关**——路径越多则单路径允许的偏移越小，从而在不同提前期之间保持可比的探索强度。
> 该规则在原论文报告过取值的两个提前期上均精确复现其精调结果：L = 2 时 Δ = 0.25，L = 5 时 Δ = 0.0884；仅在 L = 3 处给出更保守的 0.1768（原文取 0.25）。因此本规则可视为对原论文调参规律的闭式提炼而非偏离：它以单一表达式替代了逐 L 手工搜索，并可自然外推到原论文未报告的提前期（如 L = 4 时 Δ = 0.125）。**本文的全部数值实验取 L = 2，此处两者取值完全相同。**

## D3【中·须在跑 p=0.9 网格前处理】权重下界可为负，而季节性支路未对订货量做非负截断

**问题链条**：

1. 教师权重 P = (1−p, p)（L = 2）。取 p = 0.9 时 P = (0.1, 0.9)。
2. 权重盒下界为 P_j − Δ = (0.1 − 0.25, 0.9 − 0.25) = **(−0.15, 0.65)** —— 第一条路径的权重下界为负。
3. 由式 q₁ = Σ_j w̃_j·[gap_j]⁺，若网络把 η₁ 推向下界，w̃₁ < 0，则 q₁ **可能为负**。
4. 而在季节性支路上，**训练与评估两侧都没有非负截断**：
   - `train_seasonal.py:171` — `qt_I = torch.unsqueeze(action, dim=0)`（无 `relu`）
   - `main_seasonal.py:178` — `q_vector = np.append(q_vector[1:], [qt_I])`（无 `max(·,0)`）
5. 负订货量进入在途队列后，成本项 `c * q_vector[0] * y` 变为**负成本**，构成人为的成本削减。

**对照**：双源支路两侧都做了截断——`train_dual.py:185-186` 的 `q1 = F.relu(q1); q2 = F.relu(q2)`，`main_dual.py:225-226` 的 `q1 = max(float(...), 0.0)`。所以问题只存在于 seasonal 一支。

**当前影响**：p = 0.7 时下界为 (0.05, 0.45) 全为正，q₁ ≥ 0 恒成立，**已跑的演示结果不受影响**。p = 0.9 的网格单元（24 组中的一半）尚未运行。

**建议**：在 `train_seasonal.py` 的 `Env.step` 开头补 `action = F.relu(action)`，在 `main_seasonal.py` 的 `Model.test` 中补 `qt_I = max(float(qt_I), 0.0)`，与 dual 支路对齐。

## D4【中】`test_seasonal.py` 对订货量取整，与训练环境及其他策略口径不一致

**代码事实**：

```python

# test_dual.py:31
return max(q1, 0.0), max(q2, 0.0)   # ← 不取整
```

**后果**：DRL-seasonal 在**评估时执行的策略与其训练时优化的策略并不相同**（评估端被额外量化），且与对照策略的订货量口径不一致。当前 −0.82% 的微弱优势中可能混入了这一实现差异的影响，无法区分是学习所得还是量化所致。

**建议**：统一为不取整（与 dual 对齐）；若确实希望建模整数订货，则应在训练环境与全部对照策略上一并取整，并在论文中显式声明。
