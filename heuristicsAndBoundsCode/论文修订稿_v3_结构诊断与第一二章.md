## 第二部分　第一章 绪论（修订稿·可直接替换）

### 1.1 研究背景与动机

**〔第 1 段·良率场景（继承并压缩）〕**

本研究的供应侧场景承继 Yan 等（2026）的制药企业项目背景。该企业专业生产抗生素类药物，其活性成分与辅料（淀粉、胶囊等）在生产中与药品直接接触或混合，存在质量风险，因此每一批入厂物料在投入使用前必须抽样检测微生物污染；一旦抽检失败，整批货物按监管要求报废或退回，企业无法获得任何可用数量。这种"要么全部可用、要么全部不可用"的供应特征被称为全有或全无（all-or-nothing）良率模式。该模式在生物制造中普遍存在：冻干等工艺环节的温度、湿度、pH 值等物理化学参数一旦因染菌、人为差错或设备故障偏离预设控制区间，整批产出即须废弃（Tomlin, 2009; Martagan et al., 2016, 2020）。由于检测在到货时立即完成，企业在下单时并不知道该批货是否可用，却必须为提前期 L 期之后的需求做出决策——供应侧的不确定性因而与提前期叠加，构成本问题的第一重困难。

**〔第 2 段·需求侧的季节性（新增）〕**

在上述供应侧特征之外，药品需求还表现出显著的时间非平稳性。抗感染类药物的终端消耗与呼吸道感染、流行性感冒等疾病的流行强度直接相关，而这类疾病在温带地区具有稳定的年度周期：流行季处方量集中攀升，非流行季则回落至基线水平；疫苗与抗病毒药物的季节性更为刚性，其需求高峰由接种季与流行季的日历位置决定，而非由价格或促销驱动【实证依据待补文献】。这一周期性有三点建模含义。其一，需求的**均值**随时间起伏，且周期长度 τ 远大于盘点周期，因此在以周为单位、长度为 T 的规划期内表现为低频的平滑波动，而非高频噪声。其二，需求的**波动幅度**与均值同向变化：流行季不仅处方总量上升，医疗机构之间、日与日之间的离散程度也同步放大，因此本文采用乘性刻画 σ(t)=cv·μ(t)，即变异系数 cv 在周期内保持恒定，旺季的绝对波动更大而相对波动不变（这一假设的辩护见 3.3 节）。其三，周期相位是**可预知的确定性信息**而非随机扰动——企业知道当前处于流行季的哪个位置，这一信息若不被策略利用，即构成可避免的效率损失。

**〔第 3 段·供应侧的应急渠道（新增）〕**

为在流行季保障药品可及性，企业在常规长约采购之外保留了应急补货通道。其现实形态包括：向持有已完成入厂检验之合格现货的经销商或集团内兄弟工厂紧急调拨；向备选合格供应商（second source）加急采购小批量；以及动用已完成抽检、质量状态确定的安全库存池。三者的共同特征是：单位成本显著高于常规长约价格，但交付近乎即时，且由于货物的质量状态在采购时已经确定，不再承担全有或全无的抽检风险。据此本文将应急渠道抽象为**零提前期、良率恒为一、单位成本 c₂ 高于常规单位成本 c₁** 的补充供应源。该渠道的经济合理性要求 c₁ < c₂ < b（b 为单位缺货惩罚）：若 c₂ ≥ b，则应急补货的边际收益不足以覆盖其成本，理性企业将永不启用该渠道——本文的模型在此情形下自动退化为单源系统（见 3.8 节 S₀(t) 的退化条件）。

**〔第 4 段·两项特征耦合产生的经济张力（新增，本节核心）〕**

季节性与双源若单独存在，各自对应一个经典问题：仅有季节性时，决策者面临的是**跨期问题**——何时提前建库以迎接需求高峰；仅有双源时，面临的是**跨渠道配置问题**——如何在"便宜但慢且不可靠"与"昂贵但快且可靠"之间分配订货量。两者一旦耦合，便产生一个此前文献未曾正面处理的联合权衡：**面对即将到来的需求高峰，企业应当在淡季末期用常规渠道提前囤货（承担 L 期的全有或全无风险与整个持有期的库存成本，且一旦该批抽检失败便在高峰期陷入被动），还是维持较低的常规库存、把风险敞口留到高峰期用应急渠道即时兜底（承担 c₂ − c₁ 的单价溢价）？** 该权衡的最优解并非常数：它同时取决于良率成功概率 p、提前期 L、季节振幅 A 与临界比 (b − c₂)/(b + h)，并且**随周期相位动态变化**——在升段（需求上行）与降段（需求下行）相同的库存水平应当对应不同的订货决策。正是这一"最优权衡随时间漂移"的性质，使得任何以固定阈值或固定权重为核心的启发式策略在结构上无法达到最优，从而为状态相关（state-dependent）的学习型策略留出了空间。

### 1.2 问题描述与研究挑战

**〔第 1 段·正式问题陈述〕**

基于上述场景，本文考虑如下库存控制问题：单物品、周期盘点、有限规划期 T。第 t 期需求 D_t 服从均值 μ(t) 与标准差 σ(t) 均随时间正弦变化的截断正态分布，且跨期独立。补货有两条渠道：常规渠道提前期为 L 期，其到货量受独立同分布的 Bernoulli(p) 全有或全无良率支配，单位成本 c₁ 仅在抽检通过、货物入库时支付；应急渠道零提前期、良率恒为一、单位成本 c₂ 且满足 c₁ < c₂ < b。未满足需求延期交付（backlogging），期末正库存按 h 计提持有成本、负库存按 b 计提缺货惩罚。企业的目标是求解一个订货策略，使规划期内的期望折扣总成本最小。

**〔第 2 段·四条研究挑战〕**

该问题的求解面临四重困难。**其一，状态空间的进一步膨胀。** 原问题的状态已包含库存水平与 L−1 维在途订单向量，动态规划求解随 L 呈指数增长而不可行（Powell, 2007; Puterman, 2014）；非平稳需求迫使状态额外纳入时间维度，维数灾难进一步加剧。**其二，最优策略结构未知且更趋复杂。** 在单源平稳设定下最优策略的结构尚且未知，本文的有限期非平稳双源设定下更无结构性结果可依，精确的值迭代与策略迭代方法失去立足点。**其三，双渠道决策无法由两个独立阈值叠加刻画。** 常规与应急渠道的订货量并非可分离决策：常规渠道的库存水位直接决定应急渠道的触发概率，而应急渠道的可得性又反过来允许常规渠道运行在更低的安全库存上；把两个单独最优的静态启发式简单相加，得到的既非联合最优、也不具备联合最优的结构形式。**其四，教师策略本身不再近优。** 原论文以加权报童启发式（WNH）作为深度强化学习的唯一先验锚点与损失基准，其前提是 WNH 在单源平稳设定下已经足够好；而在双源场景下 WNH 仅覆盖常规渠道、根本不构成可比基准，先验锚定的设计因此需要相应重构（见 4.2 节与注记4.4）。

**〔第 3 段·原论文框架的两点未竟之处〕**

Yan 等（2026）为"单源＋平稳需求＋全有或全无良率＋非零提前期"建立了有限期 MDP 框架，沿线性膨胀规则（LIR）与加权报童启发式（WNH）两条谱系提出了梯度下降搜索启发式（GDSH）与定制深度强化学习算法，并证明了路径加权结构下总成本对权重向量的凸性。就本文关心的问题而言，该框架留下两点未竟之处。**其一是需求的独立同分布假设。** 值得注意的是，原论文附录 C 专门考察了把时间索引 t 加入网络输入的"时间感知"变体，结论是在其平稳设定下并无显著增益。这一**零结果恰恰是本文的立论起点而非反证**：在独立同分布的需求下，时间索引不携带任何关于未来需求分布的信息，网络输入它只是增加了一个冗余维度，无增益是理论上应有的结果；时间感知的价值只可能来自需求分布本身随时间变化的场景。原论文自身也意识到了这一点，其附录 D.2 在处理非独立同分布需求时改用了"为每一期分别训练一个智能体 θ_t"的方案——这既确认了时间信息在非平稳下的必要性，也暴露了该方案的参数效率问题（智能体数量随 T 线性增长，且各期之间无法共享经验）。**其二是单源结构。** 在全有或全无良率下，一次抽检失败意味着整批断供，单源系统除了提高安全库存别无对策；而现实中企业普遍配置应急通道，其价值恰恰在于把"整批断供"这一低频高损事件的后果限制在单期之内。

### 1.3 研究内容与主要贡献

本文的研究内容与贡献如下（括号内注明相对原论文的增量，完整差异清单见附录C）：

**(1) 模型层面**：建立了"季节性非平稳需求 ＋ 全有或全无良率常规渠道 ＋ 零提前期应急渠道"的有限期马尔可夫决策过程完整模型，给出六步单周期事件时序及其与仿真代码的逐步对应关系，并明确列出全部建模假设（新增：时变需求过程、二维动作空间、动态目标库存 SL(·) 与应急安全水位 S₀(·) 的闭式表达）。

**(2) 状态设计层面**：提出时间感知状态空间，以正弦／余弦编码捕捉周期相位、以归一化时间 t/T 刻画规划期进度，并证明三者联合构成时间索引 t 的双射，从而使扩充后的决策过程恢复马尔可夫性（相对原文附录 C：本文场景下时间输入承载真实的分布信息，其零结果与本文结论互为印证而非冲突）。

**(3) 算法层面**：提出融合多类启发式先验的单智能体双输出架构——常规渠道输出保持原文 ψ₁∘ψ₂∘ψ₃ 三模块结构，并将权重盒半宽由逐问题人工调定的标量 δ 形式化为能量归一化规则 Δ(L) = BASE·√(2/2^(L−1))，BASE = 0.25。**该规则在原论文报告取值的两个提前期上均精确复现其精调结果：L = 2 时 Δ = 0.25、L = 5 时 Δ = 0.0884**，从而以单一闭式规则替代了逐 L 手工调参（详见注记4.2）；应急渠道输出以单期报童水位为锚，经 tanh 映射在其邻域内受限缩放；相对指数损失的分母由 C_WNH 推广为联合启发式成本 C_HEUR。

### 2.1 随机良率库存模型与近似启发式

随机良率库存问题的研究可按提前期是否为零划分为两支。在零提前期一支，Henig 与 Gerchak（1990）对随机比例良率模型给出了系统的结构性分析，证明最优补货策略由一个**时变的临界目标库存水平**刻画，且订货量与库存位置之间呈非线性关系——这与确定性良率下的基准库存（base-stock）规则形成鲜明对比。由于该最优策略的计算复杂度在实践中难以承受，后续研究转向近似：Bollapragada 与 Morton（1999）提出报童型与 NLH-2 启发式，Li 等（2008）给出界与启发式，Huh 与 Nagarajan（2010）则提出**线性膨胀规则**（linear inflation rule, LIR），即订货量取目标水平与库存位置之差乘以平均良率的倒数，以简单的线性形式换取计算上的可行性。Federgruen 与 Yang（2011）将 Henig-Gerchak 模型推广至多供应商情形，Li（2017）进一步考察了两个存在随机良率与全有或全无风险的供应商之间的最优采购策略。

在非零提前期一支，研究数量显著减少。Inderfurth（2009）将 Bollapragada 与 Morton（1999）的参数确定方法推广至非零提前期；Inderfurth 与 Vogelgesang（2013）在随机需求与多类良率随机性下给出了安全库存的闭式近似公式，**该公式即本文式(3-6)的静态原型**；Inderfurth 与 Kiesmüller（2015）则聚焦于平稳线性膨胀策略类。以上工作均在一般形式的良率随机性下展开，未充分利用特定良率模式的结构。Chen 等（2018）针对全有或全无模式提出加权报童启发式（weighted newsvendor heuristic, WNH）：由于每笔在途订单的到货结果只有"全到"与"全不到"两种可能，L−1 笔在途订单的良率实现共构成 2^(L−1) 条样本路径，对每条路径计算其理想订货量后按路径概率加权平均即得订货决策。该方法充分利用了全有或全无模式的组合结构，在数值实验中表现良好。Yan 等（2026）在此基础上指出 WNH 的两点局限：**其一是短视（myopic）**，其权重仅由良率概率决定而未优化规划期内的总成本；**其二是权重与状态无关**，对不同的库存水平与在途订单组合给出相同的加权方式。这两点局限正是其提出梯度下降搜索启发式（GDSH，优化状态无关权重）与深度强化学习方法（输出状态相关权重）的直接动因，也是本文进一步扩展的起点。

### 2.2 双源采购与供应风险缓释

供应中断可视为随机比例良率的特例，且当中断为"全额到货或零到货"时与全有或全无良率模式在数学上等价（Wang et al., 2010; Tang et al., 2014）。缓释供应风险的手段主要有三类：提高安全库存、改进供应过程可靠性、以及引入备用供应源。Wang 等（2010）在统一框架下比较了双源采购与过程改进两条路径，指出二者的优劣取决于中断概率与改进成本的相对大小。随机良率模型在装配系统（DeCroix, 2013）、不同支付方式（Kouvelis et al., 2018）与供应链金融（Yuan et al., 2021）等场景中均有应用，但其关注点与本文不同。Federgruen 与 Yang（2011）与 Li（2017）虽已考察多源／双源下的最优采购策略，但其模型均设定零提前期或忽略在途订单的良率不确定性，因而无法刻画本文中"常规渠道存在 L 期提前期且在途订单随时可能整批作废"这一核心张力。

**本文与该脉络的差异在于**：现有双源文献多以"两个渠道均为静态可靠性参数"为前提比较渠道配置，而本文的应急渠道是在**非平稳需求下按周期相位动态触发**的——其价值不仅体现在渠道本身的可靠性，更体现在与季节相位的时序匹配上。

### 2.3 深度强化学习在库存管理中的应用

强化学习（RL）擅长求解序贯决策问题，深度神经网络（DNN）则能有效缓解维数灾难，二者结合形成的深度强化学习（DRL）近年来在库存管理领域获得了大量探索性应用，Boute 等（2022）为此提供了系统的路线图式综述。就代表性工作而言：Gijsbrechts 等（2022）验证了异步优势演员—评论家（A3C）算法可有效求解丢失销售、双源采购与多级库存三类经典问题；Oroojlooyjadid 等（2022）提出塑形奖励深度 Q 网络（SRDQN）以求解啤酒博弈；De Moor 等（2022）在易腐品库存问题中利用启发式领域知识对奖励进行塑形，显著改善了深度 Q 网络的表现；Kaynov 等（2024）针对一仓多零售商系统提出基于随机配给策略的 DRL 方案；Wang 与 Minner（2024）以近端策略优化（PPO）求解在线零售的需求履约问题。

这些工作共享一条方法论线索：**纯粹的"从零试错"在库存问题上样本效率低且训练不稳定，因此把已有启发式的领域知识注入学习过程（作为初始解、奖励塑形项或结构先验）是提升性能与稳定性的关键**。Yan 等（2026）将这一思想推进到了策略结构层面——不是把启发式作为奖励基线，而是把启发式的**权重直接作为网络输出的可行域中心**，使网络仅在教师邻域内搜索偏移量。本文继承并推广了这一设计：在双输出结构下，常规渠道锚定于 WNH 路径权重、应急渠道锚定于报童水位，形成**双重教师锚定**。

### 2.4 非平稳需求与时间感知强化学习

将时间信息纳入状态是求解有限期与非平稳 MDP 的标准做法，其理论依据来自两方面。**其一是有限期效应**：Bertsekas（2019）指出，任何有限视野动态规划或强化学习问题的最优策略本质上是非平稳的（依赖于时间步），若要以单一神经网络拟合这类策略，状态扩充（把时间索引视为状态的一部分）是必需的。Pardo 等（2018）在实验层面提出了同一主张：因时间限制而触发的终止属于环境的一部分，剩余时间应作为智能体输入的一部分，否则将违背马尔可夫性；其时间感知版本的 PPO 即通过拼接归一化剩余时间标量实现。**其二是环境非平稳性**：Mao 等（2024）指出，当奖励或转移分布随时间漂移时，若状态中不含时间或相关上下文变量，算法将无法识别环境漂移，其后悔界（regret bound）不能保证收敛。

在库存管理领域，处理非平稳需求的具体做法可分为两类。**显式预测嵌入**：Dehaybe 等（2023）★ 将未来 H 期需求分布的参数直接放入状态向量，在线性增长、线性下降、正弦季节波动等多种非平稳场景下验证了 DRL 智能体可学到接近动态规划最优解的补货策略。**隐式相位编码**：Maggiar 等（2025）★ 在真实零售数据上把"距离下一个圣诞节的周数"作为时间序列特征放入状态，以处理节假日高峰。本文采用后一类做法并将其形式化：以三角函数编码周期相位、以归一化时间编码规划期进度，二者合计仅增加三个维度即可唯一确定时间索引（见 3.5 节命题）。相较于显式预测嵌入，该方案的状态维度不随预测窗口 H 增长；相较于原论文附录 D.2 的"每期一个智能体"方案，该方案实现了跨期参数共享，智能体数量与 T 无关。

### 2.5 文献缺口与本文定位

综合上述四条脉络，可以识别出一处此前未被填补的交叉空位：

- 随机良率一支（2.1）已有针对全有或全无模式与非零提前期的高效启发式与 DRL 方法，但**均建立在需求独立同分布与单一供应源的假设之上**；
- 双源采购一支（2.2）已充分论证备用供应源的风险缓释价值，但**多在零提前期或确定性良率下展开，且渠道触发规则是静态的**；
- DRL 应用一支（2.3）已确立"启发式先验注入"的方法论共识，但**在全有或全无良率与双源耦合的场景下，先验应当如何构造尚无定论**——单一教师已不足以覆盖二维动作空间；
- 时间感知一支（2.4）已从理论上确立时间入状态的必要性，但**其在随机良率库存问题上的价值边界尚未被界定**：原论文附录 C 在平稳需求下报告了零结果，而非平稳下是否兑现价值缺乏针对性验证。

本文的定位即在这一交叉空位上：**在全有或全无良率与非零提前期的基准框架内，同时引入季节性非平稳需求与零提前期应急渠道，构造双重教师锚定的单智能体双输出 DRL 求解架构，并通过消融实验直接检验时间感知在该问题类上的价值边界。**
